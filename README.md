# Practical 1.0 自用版（Level 1 盲听卡）

听 2 秒英语 → 从四张图里选一张 → 选错了不给中文，只给慢速重播。一天 3 轮 × 10 题，大约 8～10 分钟。

- **只给 Amos 一个人用**：不登录、不收费、不同步，成绩只存你这台设备的浏览器。
- **跑在哪**：Cloudflare Worker（免费额度内）。30 个场景的图和音频放在仓库的 `media/`，构建时和网页一起部署，**不用 R2、不用绑卡**。地址先用 `workers.dev` 免费子域名。
- **怎么上线**：按《[上线操作手册](上线操作手册.md)》走，共 6 步，不用碰命令行。
- **代码怎么读**：《[项目地图](项目地图.md)》→《[项目索引](项目索引.md)》。协作规则和内部文档在 `dollar3651314/agents` 仓库的 `项目/Practical/`。

## 现在能用到什么程度
网站本身做完了；**30 个场景里齐了 21 个**（01～19、21、26；场景 20 缺虚词数字干扰图，22～25、27～30 还没生成），所以首屏会写「素材齐了 21 / 30」。
剩下的按《素材方案-交给Amos的生产包》生成，拖进 `media/` 提交就行（见《上线操作手册》第四步）：齐几个就出几题，缺的自动跳过。

## 常用命令
| 做什么 | 命令 |
|---|---|
| 本地起一份 | `npx wrangler dev` |
| 类型检查 | `npm run typecheck` |
| 单元测试 | `npm test` |
| 浏览器级验收（S1～S17） | `node scripts/e2e-app.mjs` |
| 看素材齐了没有 | `node scripts/check-media.mjs` 或 `node scripts/check-media.mjs --url <网址>` |
