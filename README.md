# Practical 1.0 自用版（盲听卡 + 发音训练）

两块互不打扰的东西：

- **盲听卡**（首页）：听 2 秒英语 → 从四张图里选一张 → 选错了不给中文，只给慢速重播。一天 3 轮 × 10 题，大约 8～10 分钟。
- **发音训练**（`/pron`，2026-11-12 从工作台整块搬过来）：七组最容易混的音，一组四步——**跟我做**（一次只说一句话，你做完点一下才给下一句）→ **对照听** → **同一组连考 10 题** → **对 8 题过关**，给那一组的绕口令。另有🎤**纠说**（你念、机器听，它只告诉你*听成了哪个词*，不判对错）和🪞**照镜子**（画面不离开你的手机）。

- **只给 Amos 一个人用**：不登录、不收费。盲听卡的成绩只存你这台设备的浏览器；发音训练的成绩和那 56 个词的发音存在服务器上（换台设备接着练）。
- **跑在哪**：Cloudflare Worker（免费额度内）。30 个场景的图和音频放在仓库的 `media/`，构建时和网页一起部署，**不用 R2、不用绑卡**。发音训练用 D1 和 Workers AI，**也都在免费额度里，不花钱**。地址先用 `workers.dev` 免费子域名。
- **怎么上线**：按《[上线操作手册](上线操作手册.md)》走，共 6 步，不用碰命令行。
- **代码怎么读**：《[项目地图](项目地图.md)》→《[项目索引](项目索引.md)》。协作规则和内部文档在 `dollar3651314/agents` 仓库的 `项目/Practical/`。

## 现在能用到什么程度
网站本身做完了；**30 个场景里齐了 21 个**（01～19、21、26；场景 20 缺虚词数字干扰图，22～25、27～30 还没生成），所以首屏会写「素材齐了 21 / 30」。
剩下的按《素材方案-交给Amos的生产包》生成，拖进 `media/` 提交就行（见《上线操作手册》第四步）：齐几个就出几题，缺的自动跳过。
