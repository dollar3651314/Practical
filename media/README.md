# media：素材放这里

页面通过 `/media/<文件名>` 读这里的文件。**全部平着放，不要建子文件夹。**

## 文件名（一个字母都不能改）

一个场景五个，编号 `01`～`30`：

| 槽位 | 文件名 | 允许的后缀 |
|---|---|---|
| 正确图 | `scene-01-correct.jpg` | `.jpg` `.png` `.webp` |
| 音素干扰 | `scene-01-d1-phoneme.jpg` | 同上 |
| 动作干扰 | `scene-01-d2-action.jpg` | 同上 |
| 虚词/数字干扰 | `scene-01-d3-function.jpg` | 同上 |
| 音频 | `scene-01-audio.mp3` | `.mp3` `.m4a` `.wav` |

名字写错的文件不会被当成素材，也不会报错，表现是「这一题一直缺」。

## 现在齐了多少

**21 个场景齐了**（01～19、21、26），**场景 20 缺 `scene-20-d3-function`**，**22～25、27～30 还没生成**。

素材没齐不影响用：一轮只从齐了的场景里出题；单题缺文件只出一个哑喇叭图标然后自动跳过，**不算答错**。

## 怎么补

1. 在工作平台的素材生成器里导入 agents 仓库的 `项目/Practical/素材方案-待生成.json`（只含没生成的 9 个场景、41 个任务）。
2. 生成完，在 GitHub 网页上点 **Add file → Upload files**，把文件拖进这个文件夹，提交。
3. 等 CI 自动部署约 3～5 分钟，刷新网址就有了。
